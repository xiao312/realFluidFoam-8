# Homogeneous-root policy point control

The exact failed53-species Cavalieri point is queried with the existing homogeneousGibbs selector enabled uniformly for all species. Largest-root S05 evidence is retained. Only root policy changes: pressure,composition,critical data,NASA coefficients,enthalpy target and acceptance remain unchanged. This tests fixed-composition homogeneous branch selection, not composition-changing VLE or a CFD restart. It uses the already qualified R54 binary/library products. Actual12-pass inversion exits and temperature-scan CSVs determine the result; a successful wrapper only delivers evidence. Node/Bash syntax and hashes precede submission through FlamePilot Slurm. A dry-run preparation plan is available before applying the point configuration. No secrets or external network are required.
