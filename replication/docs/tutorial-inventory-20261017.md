# Bundled tutorial inventory — 2026-10-17

The tested upstream revision `48506de20ce67f35279c5347b09dcd86865a4c39` contains **four case directories with `system/controlDict`**: one one-dimensional advection case and three nitrogen-jet LES variants. It contains **no counterflow flame or premixed flame-speed tutorial**, and no nitrogen–hydrogen coaxial Case D4. ## Executable and dependencies

All four `controlDict` files declare **`application reactingFoam`**. However, the [nitrogen tutorial instructions](https://github.com/danhnam11/realFluidFoam-8/blob/48506de20ce67f35279c5347b09dcd86865a4c39/tutorials/N2.jet.LES/ReadMeFirst.txt) explicitly direct the user to run `blockMesh` followed by **`realFluidFoam`**. The [LEMOS job script](https://github.com/danhnam11/realFluidFoam-8/blob/48506de20ce67f35279c5347b09dcd86865a4c39/tutorials/N2.jet.LES/c3.PR.LEMOS/job.sh) also explicitly sets `solver=realFluidFoam`. Thus an automation wrapper that trusts the stale application entry can select the wrong executable. The actual command line determines the executable; our controlled campaigns explicitly select their intended solver.

The [package README](https://github.com/danhnam11/realFluidFoam-8/blob/48506de20ce67f35279c5347b09dcd86865a4c39/README.md) requires OpenFOAM 8 and compilation through `Allwmake`, with `LIB_rfFoam8_SRC` pointing to the custom sources. The standard cases need those compiled custom real-fluid libraries and executable. Parallel operation additionally needs mesh decomposition and MPI. The jet decomposition dictionaries request scotch with 64 subdomains for c3 variants and 32 for c4.

The [LEMOS README](https://github.com/danhnam11/realFluidFoam-8/blob/48506de20ce67f35279c5347b09dcd86865a4c39/tutorials/N2.jet.LES/c3.PR.LEMOS/README.txt) requires the separately installed `danhnam11/LEMOS-8` package. Its control dictionary loads `libInflowGenerator.so`, and its inlet uses `decayingTurbulenceInflowGenerator`. This external dependency has not been qualified by the current counterflow environment build. The supplied `job.sh` uses a site-specific Grid Engine/MPI setup, not our SCNet Slurm interface. No `Allrun` or `Allclean` tutorial scripts are tracked at this revision.

## Relationship to the papers and preparation gaps

The 2025 paper (CPC 312, 109600), Table 1 and Section 4.1, identifies nitrogen jet Cases 3 and 4 with the same inlet temperatures and speeds as the c3/c4 tutorials. These directories are useful starting points, but they are **not exact ready-to-run copies of every published setup**:

- The paper specifies **3.98 MPa**, whereas all three jet `0/p` files specify **3.97 MPa**.
- Section 4.1.2 specifies approximately **4.158 million cells**; c4 matches that count, whereas both c3 directories have **3.8016 million**.
- The paper describes turbulent inflow fluctuations. Only `c3.PR.LEMOS` enables the generator. In c3.PR and c4.PR, the generator block is commented out and the inlet is a fixed uniform velocity.
- The paper specifies a no-slip front wall, whereas all three jet `0/U` files set `frontWall` to **zeroGradient**. This discrepancy must be resolved before claiming paper-equivalent boundary conditions.
- The c3 control dictionaries leave the supplied `fieldAverage` include commented out. c4 enables it, but its configured averaging starts at **0.15 s**, after its **0.01 s** stop time. Therefore the distributed default controls do not generate the intended developed averaging window. See [c3 averaging configuration](https://github.com/danhnam11/realFluidFoam-8/blob/48506de20ce67f35279c5347b09dcd86865a4c39/tutorials/N2.jet.LES/c3.PR/system/fieldAverage) and [c4 averaging configuration](https://github.com/danhnam11/realFluidFoam-8/blob/48506de20ce67f35279c5347b09dcd86865a4c39/tutorials/N2.jet.LES/c4.PR/system/fieldAverage).
- The jet `setFieldsDict` files contain CH4/O2/N2 mixture values unrelated to the active pure-nitrogen species list. The provided run instructions do not invoke `setFields`; do not add that step blindly. See [c3 setFieldsDict](https://github.com/danhnam11/realFluidFoam-8/blob/48506de20ce67f35279c5347b09dcd86865a4c39/tutorials/N2.jet.LES/c3.PR/system/setFieldsDict) and [active species list](https://github.com/danhnam11/realFluidFoam-8/blob/48506de20ce67f35279c5347b09dcd86865a4c39/tutorials/N2.jet.LES/c3.PR/constant/thermo.inputData).
- The 2025 nitrogen–hydrogen coaxial Case D4 (Section 4.2, Table 2; 4 MPa, 140/270 K, 5/60 m/s) is **not bundled**. Neither are separate SRK jet cases or the adjusted-temperature 128.53 K c3 variant used in the paper's sensitivity study.

The 1D case is a separate nonreacting advection check; it is not a 2022 flame case. Its complete initial temperature field and matching `setFieldsDict` are present. The 2022 methane properties, counterflow configurations, and flame-speed sweep must be supplied by our replication layer. The absence statement is bounded to this pinned **realFluidFoam-8** tree, not every repository in the author's solver family.
