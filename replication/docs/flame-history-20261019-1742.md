## Definition and provenance

For each side, fit front position over the trailing 5 us, subtract the local gas
velocity, multiply by local/front-to-fresh density ratio, average within the fit
window, and orient the sign into fresh gas. Curves average left and right values;
bands show their range, not statistical uncertainty. Temperature uses each
condition's fixed Cantera anchor; OH uses mass fraction 2e-5. Invalid or incomplete
windows remain gaps. There is no additional smoothing.

Stock and DeepFlame line samples are processed by the same C++ tracking core as
native runtime histories. The newest two sample directories are excluded to avoid
partial writes, and file size/mtime are checked around each read. Native CSVs have
no truncated trailing rows in this capture. Offline input requires 8000 matching
coordinates per profile. Native trajectories start from the shared 50.018-us
restart; stock/DeepFlame start from the original central products at zero.
Transport differs between solver families.
